# Panel comercial · Culligan Biofy

Panel de producción y ventas (comerciales, VIP, teleoperadoras y consultores técnicos).

- La página está protegida con contraseña. Sin ella no se ve ningún dato.
- Los datos y las versiones guardadas viven en un repositorio **privado** aparte; este repositorio solo contiene la página.
- Para actualizar: exportar los Numbers a Excel (Archivo › Exportar a › Excel), subirlos en el panel y pulsar «Guardar» (modo administrador).
